plan_grasp(depth: numpy.ndarray, intrinsics: numpy.ndarray, segmentation: numpy.ndarray) -> tuple[numpy.ndarray, numpy.ndarray]
  Doc:
    Plan gripper TCP grasp candidates using Contact-GraspNet.
    
    The raw Contact-GraspNet poses are shifted by 0.12 m along each
    grasp's local +Z axis before they are returned. The returned poses
    therefore already include the Contact-GraspNet-to-TCP position offset;
    the caller must not add another TCP or gripper-length offset.
    
    This function does not transform poses from camera to robot/world
    coordinates. Apply the camera-to-world transform exactly once before
    passing a selected pose to ``solve_ik`` or ``goto_pose``.
    
    Args:
        depth:
            Depth image in meters.
            Shape: (H, W) or (H, W, 1), dtype float32/float64.
        intrinsics:
            Camera intrinsic matrix.
            Shape: (3, 3), dtype float64.
        segmentation:
            Instance segmentation map where each integer > 0 corresponds to a
            unique object instance ID.
            Shape: (H, W) or (H, W, 1), dtype int32/int64.
    
    Returns:
        grasp_poses:
            np.ndarray of shape (K, 4, 4), dtype float64.
            Candidate gripper TCP poses in the camera frame, with the local
            +Z 0.12 m offset already applied.
        grasp_scores:
            np.ndarray of shape (K,), dtype float64.
            Confidence score for each candidate grasp.
    
    Example:
        >>> cam = obs["agentview"]
        >>> rgb = cam["images"]["rgb"]
        >>> depth = cam["images"]["depth"]
        >>> sam3_results = sam3_seg_fn(rgb, text_prompt="red mug")
        >>> best = max(sam3_results, key=lambda d: d["score"])
        >>> mask = best["mask"]
        >>> K = cam["intrinsics"]
        >>> grasp_poses, grasp_scores = plan_grasp(
        ...     depth=depth,
        ...     intrinsics=K,
        ...     segmentation=mask,
        ... )
        >>> best_idx = grasp_scores.argmax()
        >>> best_T_camera_tcp = grasp_poses[best_idx]
        >>> camera_to_world = cam["pose_mat"]
        >>> best_T_world_tcp = camera_to_world @ best_T_camera_tcp

solve_ik(position: numpy.ndarray, quaternion_wxyz: numpy.ndarray) -> numpy.ndarray
  Doc:
    Solve panda_hand inverse kinematics for a desired gripper TCP pose.
    
    ``position`` and ``quaternion_wxyz`` describe the desired gripper
    TCP/contact-center pose in the robot/world frame, not a panda_hand pose.
    After clipping the requested TCP position to the reachable workspace,
    this function internally applies ``[0.0, 0.0, -0.10]`` m in the
    requested pose's local frame to obtain the panda_hand IK target. Do not
    apply a TCP or gripper-length offset before calling this function.
    
    The requested orientation is attempted first. If IK fails, the function
    tries its built-in top-down, 45-degree-tilt, and side-approach
    orientations; the TCP offset is recomputed for each fallback orientation.
    
    Args:
        position:
            Desired gripper TCP/contact-center position in the robot/world
            frame. Shape: (3,), dtype float64.
        quaternion_wxyz:
            Desired gripper TCP orientation in the robot/world frame.
            Shape: (4,), [w, x, y, z], dtype float64.
    
    Returns:
        joints:
            np.ndarray of shape (7,), dtype float64.
            Joint angles for the 7 DoF Franka arm. A successful fallback may
            correspond to an orientation different from the one requested.
    
    Example:
        >>> target_tcp_pos = np.array([0.5, 0.0, 0.3])
        >>> target_tcp_quat = np.array([1.0, 0.0, 0.0, 0.0])  # wxyz
        >>> joints = solve_ik(target_tcp_pos, target_tcp_quat)
        >>> move_to_joints(joints)

goto_pose(position: numpy.ndarray, quaternion_wxyz: numpy.ndarray, z_approach: float = 0.0) -> None
  Doc:
    Move the gripper TCP to a desired pose with optional approach motion.
    
    This function combines ``solve_ik`` and ``move_to_joints``. The input is
    a desired gripper TCP/contact-center pose in the robot/world frame;
    ``solve_ik`` applies the TCP-to-panda_hand offset internally, so the
    caller must not add a TCP or gripper-length offset.
    
    If ``z_approach > 0``, the function first moves to
    ``position + [0, 0, z_approach]`` in world coordinates and then moves to
    ``position``. The approach is along world +Z, not the gripper's local Z
    axis. A non-positive value disables the approach waypoint. Do not also
    add a separate world-Z pre-approach offset unless an additional waypoint
    is intentionally required.
    
    Args:
        position:
            Desired gripper TCP/contact-center XYZ in meters in the
            robot/world frame.
        quaternion_wxyz:
            Desired gripper TCP orientation as a WXYZ unit quaternion in the
            robot/world frame.
        z_approach:
            Optional world +Z approach distance in meters. Default 0.0.
    
    Example:
        >>> target_tcp_pos = np.array([0.5, 0.0, 0.3])
        >>> target_tcp_quat = np.array([0.0, 1.0, 0.0, 0.0])
        >>> goto_pose(target_tcp_pos, target_tcp_quat, z_approach=0.075)
